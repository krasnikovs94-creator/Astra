# Астра — веб-приложение для iPhone

## Установка через GitHub Pages
1. Создайте публичный репозиторий, например `astra`.
2. Загрузите файлы **из архива в корень репозитория** (не сам ZIP).
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Откройте `https://ВАШ-ЛОГИН.github.io/astra/` в Safari, затем Поделиться → На экран «Домой».

## Что работает
- Интерфейс чата, история сообщений в браузере.
- Озвучивание через системный speechSynthesis (зависит от iOS).
- Голосовой ввод через Web Speech API только в поддерживаемых браузерах; на iPhone может быть недоступен.
- PWA и базовое кеширование для офлайн-запуска интерфейса.

## Подключение GPT
Статический сайт не должен содержать секретный ключ OpenAI. В настройках можно задать HTTPS URL **своего серверного посредника**, который принимает POST JSON `{ "messages": [{"role":"user","content":"Привет"}] }` и возвращает `{ "reply":"Здравствуйте!" }`. Сервер обязан безопасно хранить API-ключ, проверять запросы, ограничивать нагрузку и разрешать CORS для домена приложения. Пока сервер не подключен, GPT-ответы не работают.
